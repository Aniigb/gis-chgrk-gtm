# ГТМ зданий и сооружений. ООО «Черногорская ГРК»

Публичная версия системы геотехнического мониторинга (ГТМ) зданий и сооружений
Черногорского горно-обогатительного комбината (ООО «Черногорская ГРК»).

- Реестр: 211 объектов в 10 группах (здания, сооружения, ГТС, дороги, ЛЭП, сети),
  202 объекта геопозиционированы (МСК-165 → WGS-84).
- Карта: маркеры объектов, контрольно-измерительная аппаратура (85 пунктов КИА
  плотины ГТС и автодороги №12), ортофотоплан 2023 (4 см, АФС ЧГОК), кадастровые
  границы ЗУ, тепловая карта грунтов.
- Данные зашифрованы (AES-GCM); доступ по паролям ролей:
  «Наблюдатель» / «Оператор» / «Надзор».
